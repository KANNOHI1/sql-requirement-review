## 罠チェック
- T01 JOIN での行の水増し: 該当なし。`products` を自身の ID 列（`s.product_id = p.product_id`）だけで結合しており 1 対 1 とみなせる
- T02 INNER JOIN での欠落: 該当なし。要件は「実績のあるブランドの売上合計」で、実績ゼロのブランドや全商品の網羅を求めていない
- T03 NULL 行の脱落: 該当なし。`<>` / `NOT IN` / `=` による除外条件はなく、期間条件の `sale_ts` も NULL 可とは定義されていない。`amount` の NULL は指標定義で除外してよいとされている
- T04 COUNT と COUNT(DISTINCT) の取り違え: 該当なし。件数を数える要件も SQL もない（合計のみ）
- T05 WHERE と HAVING の位置: 該当なし。集計結果で絞る要件がない
- T06 タイムゾーン: 該当なし。`DATE(s.sale_ts, 'Asia/Tokyo')` で JST に変換している
- T07 期間境界: 該当なし。変換後は DATE 型なので `BETWEEN ... AND DATE '2026-06-30'` で 6/30 を丸ごと含む。6 月は 30 日で末日も正しい
- T08 返品・マイナス行・NULL 金額の扱い: 該当なし。`amount > 0` などでマイナス行を除外しておらず、指標定義「売上（返品を引く）」と一致。NULL は SUM が無視し、定義上も除外してよい
- T09 指標定義のズレ: 該当なし。`sales.amount`（実売金額・税抜）の合計で、指標定義の「売上」と一致。定価（`list_price`）×数量ではない
- T10 最新スナップショットの選び方: 該当なし。スナップショット表（`stock`）を使っていない
- T11 ゼロ除算・比率の計算: 該当なし。割り算・比率がない
- T12 ORDER BY 無しの LIMIT・同順位の扱い: 該当なし。「上位 N 件」の要件も `LIMIT` もない
- T13 表・列の選び違い: 該当なし。`dojo.sales`（取引の正本。生データの `sales_raw` ではない）、`dojo.products`、列 `brand` / `amount` / `product_id` / `sale_ts` はすべてテーブル定義に存在し、要件の言葉（ブランド・売上・6 月）に対応する
- T14 元データの重複行: 該当なし。使っているのは重複を除いた正本 `sales` で、重複が入りうる `sales_raw` ではない
- T15 文字列の一致ミス: 該当なし。文字列の比較条件（`=` / `IN` / `LIKE`）がない

## 読み下し（Alteryx 対応付き）
テーブル定義との照合（先に実施）:
- `dojo.sales`（別名 s）: 存在。取引の正本。`sale_ts`（TIMESTAMP）、`product_id`、`amount`（INT64・実売金額・税抜・NULL 可）はいずれも定義にある。要件の「売上」に対応
- `dojo.products`（別名 p）: 存在。`product_id`、`brand` はいずれも定義にある。要件の「ブランド」に対応
- 定義に無い表・列: なし

実行順の読み下し:
1. FROM `dojo.sales` s / JOIN `dojo.products` p ON `s.product_id = p.product_id`（Alteryx: 入力データ 2 本＋結合ツール。J 出力のみを使い、L・R 出力は捨てる）。商品 ID で取引に商品マスタのブランドを付ける処理
2. WHERE `DATE(s.sale_ts, 'Asia/Tokyo') BETWEEN 2026-06-01 AND 2026-06-30`（Alteryx: フィルター。集計前）。取引日時を JST の日付に直し、6/1〜6/30 の行だけ残す
3. GROUP BY `p.brand` ＋ `SUM(s.amount)`（Alteryx: 集計ツール。グループ化＝ブランド、合計＝金額）
4. SELECT `p.brand, SUM(s.amount) AS sales_amount`（Alteryx: 列の選択。計算式のフォーミュラはなし）
5. ウィンドウ関数・HAVING・ORDER BY・LIMIT はなし

この SQL が実際に答えている質問: 取引日時が JST で 2026 年 6 月 1 日〜30 日の取引について、商品マスタに登録のある商品の実売金額（税抜、返品のマイナス行を含む）を、ブランド別に合計した値はいくつか。
