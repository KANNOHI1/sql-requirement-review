## 読み下し（Alteryx 対応付き）
表名・列名の照合: `dojo.sales_raw`（要件の「取込生データ」）、`sale_id`（要件の「取引 ID」）。どちらもテーブル定義に存在する。

1. FROM `dojo.sales_raw`（入力データ）: 取込生データを全行読む。再送により同じ sale_id が複数行入りうる表。
2. GROUP BY sale_id ＋ COUNT(*)（集計ツール）: 取引 ID ごとに行数を数える。
3. HAVING COUNT(*) > 1（フィルター・集計後）: 行数が 2 以上の取引 ID だけ残す。
4. SELECT sale_id（フォーミュラ／列選択）: 残った取引 ID だけの一覧にする（サブクエリ d）。
5. 外側の SELECT COUNT(*) AS dup_id_count（集計ツール）: その一覧の行数（＝重複している取引 ID の種類数）を数える。

この SQL が実際に答えている質問: sales_raw の全期間で、2 行以上入っている取引 ID は何種類あるか。
