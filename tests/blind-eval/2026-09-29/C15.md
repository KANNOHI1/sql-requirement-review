## エンジニアへの確認質問
1. 得意先マスタ（`dojo.customers`）に「チャネル」列（`channel`、値は ドラッグ / GMS / 百貨店 / EC）があります。「ドラッグストアチャネル」を得意先名に「薬局」を含むかどうかで判断した理由は何ですか。`channel` が「ドラッグ」の得意先で絞る形に直してよいですか。
2. 得意先名に「薬局」を含む得意先のうち、チャネルが「ドラッグ」以外のものはありますか。また、チャネルが「ドラッグ」なのに名前に「薬局」を含まない得意先は何社ありますか（この 2 つの数が、今回のズレの大きさです）。
3. 得意先マスタは 1 得意先につき 1 行ですか（同じ得意先 ID が複数行入っていませんか）。入っている場合は、得意先 ID の種類数で数え直す必要があります。

## 読み下し（Alteryx 対応付き）
表名・列名の照合:
- `dojo.customers`（得意先マスタ）: 定義にある。要件の「得意先」に対応。
- `customer_name`（得意先名、STRING）: 定義にある。要件のどの言葉にも対応しない（チャネルの指定ではない）。
- `is_active`（BOOL、稼働中なら TRUE）: 定義にある。要件の「稼働中」に対応。
- 要件の「ドラッグストアチャネル」に対応する列 `channel` は、SQL に登場しない。

実行順:
1. FROM `dojo.customers`: 入力データ（得意先マスタを 1 つ読むだけ。結合なし）
2. WHERE `customer_name LIKE '%薬局%' AND is_active`: フィルター（集計前）。名前に「薬局」を含み、かつ稼働中の行だけ残す
3. `COUNT(*)`: 集計ツール（Count）。残った行数を数える
4. SELECT `AS customer_count`: 列名を付けるだけ

この SQL が実際に答えている質問: 「得意先名に『薬局』を含み、かつ稼働中の得意先は何件あるか」
