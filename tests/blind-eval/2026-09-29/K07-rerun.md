## 読み下し（Alteryx 対応付き）
1. FROM `dojo.sales_raw`（入力データ）: 取込生データを読む。JOIN なし。表・列とも定義に存在する。要件の「基幹からの取込生データ（sales_raw）」に対応。
2. 内側の SELECT sale_id + GROUP BY sale_id（集計ツール、グループ化＝sale_id）: 取引 ID ごとに 1 行にまとめる。

4. 外側の SELECT COUNT(*) AS dup_id_count（集計ツール、Count のみ）: 残った取引 ID の行数を数える。内側で ID ごと 1 行なので、重複している取引 ID の種類数になる。
