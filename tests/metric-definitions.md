# 指標の定義表（テスト用・ミツキ化粧品）

| 指標名（営業が使う言葉） | 対応する表.列 または 計算式 | 税 | 返品・訂正 | 日付の基準 | 備考 |
|---|---|---|---|---|---|
| 売上 | `sales.amount` の合計 | 税抜 | 差し引く（マイナス行を含める） | 取引日時（JST） | amount が NULL の行は集計から除外してよい |
| 販売数量 | `sales.qty` の合計 | — | 差し引く（マイナス行を含める） | 取引日時（JST） | |
| 目標達成率（全体） | Σ売上 ÷ Σ目標（`targets.target_amount`） | 税抜 | 差し引く | 月（JST） | 得意先ごとの達成率の平均ではない |
| 総売上（返品前） | `sales.amount` のうち正の値（マイナス行を除く）の合計 | 税抜 | 差し引かない（マイナス行を除外する） | 取引日時（JST） | 「売上」と違い返品を引かない。amount が NULL の行は集計から除外してよい |
| 在庫数 | `stock.stock_qty` | — | — | 最新の snapshot_date | 日付をまたいで合計しない |

## 用語の約束

| 言葉 | 意味 |
|---|---|
| 2026年6月（JST） | JST の 2026-06-01 0:00 〜 2026-06-30 23:59:59 |
| 〇〇以外 | 〇〇に当たらないものすべて。未登録（NULL）も含む |
| 店舗数 | 店舗 ID の種類数 |
